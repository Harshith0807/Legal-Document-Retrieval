# Legal Document Retrieval

A Retrieval-Augmented Generation (RAG) based system for retrieving and analyzing legal documents.

## Contents

- `team_01_report/` — full project report (LaTeX source + compiled PDF)
- `team_01_implementation_paper/` — IEEE-format implementation paper (LaTeX source + compiled PDF)
- `team_01_review_paper/` — review paper source

- `team 01 poster.pdf` — project poster
- `team_01_plag_report.pdf` — plagiarism report
- `team_01_major_project.pdf` — consolidated project document

## Overview

The project implements a RAG pipeline for legal document retrieval, evaluated using precision@k and related retrieval metrics. See `team_01_implementation_paper/rag_architecture_workflow.png` and `rag_flow_diagram.png` for the system architecture.
